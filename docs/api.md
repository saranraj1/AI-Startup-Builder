# API

OpenAPI is generated by FastAPI at `/docs` and `/openapi.json`.

- `GET /health` returns service readiness.
- `GET /api/v1/projects` lists projects for the current workspace.
- `POST /api/v1/projects` accepts `{ "idea": string }` and returns `202` with a queued project.
- `GET /api/v1/projects/{project_id}` returns progress and persisted artifacts.

Production authentication should use an HttpOnly secure session cookie backed by OAuth/JWT. Every project query must be scoped to the authenticated organization.
